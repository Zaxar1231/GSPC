# Дизайн UI: Material Design 3

> Статус: план, реализуется на этапе 3. Решение — [ADR 0006](adr/0006-material-design-3.md).

## Токены

### Цвет

Схема строится из seed-цвета (по умолчанию акцентный цвет Windows) по алгоритму MD3:
тональные палитры HCT для primary, secondary, tertiary, neutral, neutral-variant и error.

| Роль | Светлая тема (тон) | Тёмная тема (тон) | Где используется |
|---|---|---|---|
| primary / on-primary | 40 / 100 | 80 / 20 | основные кнопки, FAB «Запустить» |
| primary-container | 90 | 30 | выбранный инстанс, активная вкладка |
| secondary-container | 90 | 30 | фильтры, чипы |
| tertiary-container | 90 | 30 | акценты оверлея управления |
| surface / on-surface | 98 / 10 | 6 / 90 | фон окна, текст |
| surface-container (low…highest) | 96…90 | 10…22 | карточки, панели, диалоги |
| outline / outline-variant | 50 / 80 | 60 / 30 | границы полей, разделители |
| error | 40 | 80 | ошибки проверки системы |

### Типографика

Roboto Flex (в комплекте), фоллбек Segoe UI Variable.

| Стиль | Размер / межстрочный | Где |
|---|---|---|
| headline-small | 24 / 32 | заголовок экрана |
| title-medium | 16 / 24 | карточки инстансов |
| body-medium | 14 / 20 | основной текст |
| label-large | 14 / 20 | кнопки |
| label-small | 11 / 16 | счётчики оверлея (FPS, 1% low) |

### Форма

| Токен | Радиус | Где |
|---|---|---|
| extra-small | 4 | поля ввода |
| small | 8 | чипы, меню |
| medium | 12 | карточки |
| large | 16 | FAB, навигационный drawer |
| extra-large | 28 | диалоги |
| full | 50% | кнопки, переключатели, кнопки оверлея управления |

### Поверхности и состояния

- Глубина передаётся тоном surface-container, а не тенями (дёшево для рендера).
- Состояния — слой поверх элемента: hover 8%, focus 10%, pressed 10%, drag 16% цвета on-*.

## Экраны

| Экран | Компоненты MD3 |
|---|---|
| Менеджер инстансов | navigation rail, карточки инстансов, FAB «Новый инстанс», меню действий |
| Окно игры | экран гостя, top app bar (скрывается), оверлей метрик, панель управления |
| Настройки | списки с разделителями, switch, slider (RAM, ядра, FPS), segmented buttons (VSync / без / лимит) |
| Редактор управления | контролы-кружки (shape full, tertiary-container, прозрачность), bottom sheet свойств |
| Проверка системы | список с иконками статуса, filled tonal button «Исправить» |
| Обновления | snackbar «Доступно обновление», диалог с changelog |

## Правила производительности

- Во время игры UI не блокирует present: вершины готовятся в UI-потоке, рисуются present-потоком.
- Никаких blur и полноэкранных полупрозрачных слоёв поверх кадра гостя.
- Анимации MD3 (emphasized easing, 200–500 мс) — только вне игры.
