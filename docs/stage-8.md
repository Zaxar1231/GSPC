# Этап 8 — импорт раскладок BlueStacks

> Статус: скелет. Заблокировано: нет реальных файлов `.cfg`.

Подробный план — [bluestacks-import.md](bluestacks-import.md). Крейт `crates/bluestacks-import`
пока пустой (только описание модуля).

| # | Задача | Критерий | Статус |
|---|---|---|---|
| 8.1 | Набор реальных `.cfg` (разные игры и версии BlueStacks) в `crates/bluestacks-import/tests/fixtures/` | есть минимум 5 файлов от разных игр | ⏳ **нужны от мейнтейнера** |
| 8.2 | Структуры serde по фикстурам, неизвестные поля игнорируются | все фикстуры разбираются | ⏳ после 8.1 |
| 8.3 | Маппинг типов контролов BlueStacks → `rustdroid-input::Control` | покрыты Tap, Dpad, Pan, Swipe, MOBASkill и др. | ⏳ |
| 8.4 | Маппинг кодов клавиш BlueStacks → имена клавиш `rustdroid-input` | таблица в тестах | ⏳ |
| 8.5 | Отчёт об импорте: импортировано / с приближением / пропущено с причиной | импорт не падает из-за одного контрола | ⏳ |
| 8.6 | Автопоиск BlueStacks (реестр, стандартные пути), импорт файлом и drag-and-drop | находит установленный BlueStacks | ⏳ |
| 8.7 | Snapshot-тесты на каждую фикстуру, fuzz-тест парсера | тесты зелёные в CI | ⏳ |
