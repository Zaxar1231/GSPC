# ADR 0002: 3D через gfxstream + ANGLE-on-Vulkan в госте

- Статус: принято
- Дата: 2026-11-07

## Варианты

| | gfxstream | Venus/virglrenderer | свой протокол |
|---|---|---|---|
| Windows-хост | работает в проде (Android Emulator, Google Play Games PC) | фактически не поддерживается | писать с нуля |
| Трудозатраты | 2–4 месяца | 6–12+ месяцев, исход неясен | 1,5–3 года |

## Решение

virtio-gpu + gfxstream (C++ через FFI). В госте ANGLE — системный GLES-драйвер поверх Vulkan,
поэтому на хосте один путь: Vulkan → общий NT handle → D3D12. GLES-кодировщик gfxstream — фоллбек
для игр, несовместимых с ANGLE.

## Последствия

- C++-зависимость: отдельный FFI-слой, сборка gfxstream в CI.
- Один кэш пайплайнов на хосте, один путь interop.
