# ADR 0006: UI в стиле Material Design 3

- Статус: принято (реализация — этап 3, вместе с UI)
- Дата: 2026-11-08

## Контекст

Приложению нужен цельный современный стиль: менеджер инстансов, настройки, редактор управления,
оверлеи поверх игры. Выбран Material Design 3 (Material You).

## Решение

- UI на egui, оформленный по токенам MD3: цветовые роли (primary, secondary, tertiary, surface и
  контейнеры, outline, error), типографика (display/headline/title/body/label), шкала
  скруглений, тональные уровни поверхностей вместо теней, состояния (hover/pressed/focus).
- Палитра строится из одного seed-цвета алгоритмом MD3 (HCT, тональные палитры), светлая и
  тёмная схемы; по умолчанию — акцентный цвет Windows, если пользователь не выбрал свой.
- Тема — отдельный модуль `app::theme` с токенами, компоненты (кнопки, FAB, карточки,
  навигационная рейка, переключатели, слайдеры, диалоги, snackbar) — тонкие обёртки над egui.
- Описание дизайна — [docs/ui-design.md](../ui-design.md).

## Ограничения производительности

- Путь кадра гостя от стиля не зависит. Панели UI рисуются поверх тем же проходом, что и кадр
  гостя ([ADR 0003](0003-d3d12-compositor.md)). Размытия фона (blur) и тяжёлые эффекты во время
  игры не используются.
- Анимации MD3 (motion) — только в окне менеджера и в настройках; оверлей во время игры статичен
  или анимирует только прозрачность.

## Последствия

- Нужен свой небольшой набор компонентов поверх egui.
- Шрифты: Roboto Flex (OFL) в комплекте с фоллбеком на Segoe UI Variable.
