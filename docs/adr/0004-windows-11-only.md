# ADR 0004: только Windows 11 x64

- Статус: принято
- Дата: 2026-11-07

## Решение

Поддерживается только Windows 11 x64. Windows 10 вышла из поддержки Microsoft; урезанный режим
(без части enlightenments WHPX) не делаем.

## Последствия

- Можно опираться на API WHPX, CPU Sets и DXGI, доступные в Windows 11.
- Установщик отказывает в установке на Windows 10 с понятным сообщением.
