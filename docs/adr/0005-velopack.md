# ADR 0005: установщик и обновления на Velopack

- Статус: принято (реализация — этап 7)
- Дата: 2026-11-07

## Варианты

| | Velopack | WiX (cargo-wix) | Inno Setup |
|---|---|---|---|
| Автообновления и дельты | встроены, есть Rust SDK | нет | нет |
| Без прав администратора | да (per-user) | обычно per-machine | оба режима |
| Простота для пользователя | лучшая | средняя | хорошая |

## Решение

Velopack + отдельный `rustdroid-elevate.exe` (манифест `requireAdministrator`) только для включения
Windows Hypervisor Platform. Сверху: ed25519-подпись манифеста релизов и откат при неудачном старте
новой версии.

## Последствия

- UAC появляется только на шаге включения WHPX.
- Ассоциации и ярлыки — в HKCU через хуки установки.
