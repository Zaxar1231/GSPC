# ADR 0001: лицензия MIT OR Apache-2.0

- Статус: принято
- Дата: 2026-11-07

## Контекст

Нужна лицензия, совместимая с переиспользуемым кодом (rust-vmm — Apache-2.0/BSD-3-Clause, crosvm — BSD-3-Clause,
Firecracker — Apache-2.0) и с гостевыми компонентами (AOSP — Apache-2.0, gfxstream — Apache-2.0).

## Решение

Двойная лицензия MIT OR Apache-2.0, стандарт экосистемы Rust.

## Последствия

- Можно переносить код из rust-vmm, crosvm, Firecracker с сохранением уведомлений.
- Проприетарные форки возможны (в отличие от GPL-3.0).
- Ядро гостя остаётся GPL-2.0: публикуем его исходники и патчи вместе с образами.
- Трансляторы ARM проприетарны и не распространяются при любой лицензии проекта.
