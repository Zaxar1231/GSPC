# ADR 0003: композитор на чистом D3D12

- Статус: принято
- Дата: 2026-11-07

## Контекст

Путь кадра гостя должен идти без лишних слоёв: импорт общего NT handle, полный контроль над
waitable swapchain, `SetMaximumFrameLatency`, `DXGI_PRESENT_ALLOW_TEARING`, frame statistics.

## Решение

Крейт `present` на D3D12 через крейт `windows`, без wgpu. Панели UI (egui) рисуются поверх тем же
проходом из готовых вершин. Запасной путь — прямой Vulkan-swapchain.

## Последствия

- Около 1,5–2 тыс. строк своего кода рендера, включая egui-рендерер под D3D12.
- Никакой дополнительной валидации и трекинга ресурсов в горячем пути.
