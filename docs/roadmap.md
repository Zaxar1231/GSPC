# Roadmap

Каждый этап — отдельная ветка `feat/stage-N-<имя>`, PR и milestone. После этапа: рабочая сборка,
инструкция по запуску, тесты, замеры (FPS, время кадра, задержка ввода) в сравнении с прошлым
этапом, обновлённые README, CHANGELOG и docs.

Оценки — для одного разработчика, полный рабочий день.

## Задачи ближайших этапов

### Этап 1 — минимальный VMM

- `whpx`: биндинги через крейт `windows`, партиция, память, vCPU, регистры, отмена запуска.
- Проверки при старте: наличие гипервизора, компонент Windows Hypervisor Platform, VT-x/SVM в UEFI, запуск в ВМ без nested-виртуализации.
- `vmm`: выделение RAM с prefault, опционально большие страницы.
- Загрузка bzImage + initramfs + cmdline (64-битная точка входа).
- CPUID и MSR: маскирование, invariant TSC, enlightenments Hyper-V.
- LAPIC через WHPX, минимальный IOAPIC, ACPI MADT.
- 16550 UART → консоль хоста.
- vCPU-потоки на P-ядрах, MMCSS.
- Скрипт загрузки ядра GKI `kernel_virt_x86_64` (android15-6.6) с ci.android.com.

### Этап 2 — AOSP до шелла

- PCIe ECAM, ACPI MCFG/DSDT, MSI-X.
- virtio-pci транспорт, doorbells, EVENT_IDX.
- virtio-blk (system/vendor/userdata, CoW-оверлеи), virtio-console.
- Загрузка образов Cuttlefish x86_64, совместимость cmdline/bootconfig.

### Исследования в фоне (не блокируют этапы)

- Berberis (AOSP) как открытая база ARM64-трансляции.
- Матрица enlightenments WHPX по сборкам Windows 11.
