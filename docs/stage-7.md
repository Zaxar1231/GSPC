# Этап 7 — установщик, автообновление, релизы

> Статус: скелет. Код не начат. Решения — в [ADR 0005](adr/0005-velopack.md).

Цель: установка без лишних действий, включение Windows Hypervisor Platform по запросу,
каналы stable/beta, дельта-обновления, откат при неудачном старте.

| # | Задача | Критерий | Статус |
|---|---|---|---|
| 7.1 | Упаковка Velopack (`vpk pack`) в CI, артефакты release и beta | установщик собирается из тега | ⏳ |
| 7.2 | `rustdroid-elevate.exe` с манифестом `requireAdministrator`: включает WHPX, перезагрузку не требует | после UAC WHPX включён, отчёт о результате | ⏳ |
| 7.3 | Ассоциации `.apk`, `.xapk`, `.rdprofile` и ярлыки в HKCU | двойной клик открывает нужную команду | ⏳ |
| 7.4 | `rustdroid-updater`: каналы, дельты, фоновая загрузка, применение при перезапуске | обновление с beta на stable и обратно | ⏳ крейт-заглушка (`crates/updater`) |
| 7.5 | Подпись манифеста релизов (ed25519) и проверка до применения | подменённый манифест отклоняется | ⏳ |
| 7.6 | Откат: версия сообщает «здорова» после старта, иначе ставится предыдущая | сломанная версия откатывается сама | ⏳ |
| 7.7 | Манифест образов Android: версии, sha256, подпись, докачка через HTTP Range | образ докачивается после обрыва | ⏳ |
| 7.8 | Авторская подпись Authenticode | установщик без предупреждения SmartScreen | ⏳ решение о сертификате |

## Что нужно от мейнтейнера (до начала)

- Где хранить ключ ed25519 и кто его держит (CI-секрет или офлайн-ключ).
- Сертификат Authenticode: покупать ли, и на кого он выписан.
- Хостинг артефактов: GitHub Releases (как сейчас `deps-*`) или отдельный сервер.

## Открытые вопросы

- Нужен ли режим без установки (portable zip) — сейчас не запланирован.
- Как откатывать образы Android, если новый образ ломает совместимость с сохранённым userdata.
