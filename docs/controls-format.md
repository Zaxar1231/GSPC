# Формат профилей управления

> Статус: черновик. Формат будет зафиксирован на этапе 6 вместе с keymap-движком.

## Принципы

- JSON с полем `version` (целое) и цепочкой миграций `vN → vN+1`. Старые профили открываются
  всегда, новые поля имеют значения по умолчанию.
- Все координаты и радиусы — в **долях экрана** (0–1) в ориентации, указанной в профиле.
  При смене ориентации пересчёт делает `rustdroid-input::geometry`.
- Профиль привязан к `package` и автоматически включается, когда guest-agent сообщает, что
  игра на переднем плане.
- Клавиши — по именам виртуальных клавиш Windows (`"W"`, `"Space"`, `"LButton"`, `"Wheel"`),
  кнопки геймпада — по именам XInput (`"A"`, `"LeftStick"`, `"RT"`).

## Набросок

```json
{
  "version": 1,
  "name": "Example Shooter — по умолчанию",
  "package": "com.example.shooter",
  "orientation": "landscape",
  "controls": [
    { "type": "tap", "key": "F", "x": 0.82, "y": 0.64 },
    { "type": "joystick", "keys": { "up": "W", "left": "A", "down": "S", "right": "D" },
      "x": 0.15, "y": 0.72, "radius": 0.08, "smoothing": 0.0 },
    { "type": "aim", "toggle_key": "LAlt", "x": 0.65, "y": 0.45,
      "sensitivity": { "x": 1.0, "y": 1.0 }, "invert_y": false, "smoothing": 0.0 },
    { "type": "shoot", "key": "LButton", "x": 0.88, "y": 0.52 },
    { "type": "swipe", "key": "Space", "from": { "x": 0.5, "y": 0.8 }, "to": { "x": 0.5, "y": 0.4 }, "duration_ms": 80 },
    { "type": "repeat_tap", "key": "E", "x": 0.7, "y": 0.8, "interval_ms": 50 },
    { "type": "hold", "key": "C", "x": 0.9, "y": 0.85, "mode": "toggle" },
    { "type": "zoom", "key": "Wheel", "center": { "x": 0.5, "y": 0.5 }, "step": 0.05 },
    { "type": "macro", "key": "Q", "steps": [
        { "tap": { "x": 0.6, "y": 0.6 } }, { "wait_ms": 120 }, { "tap": { "x": 0.7, "y": 0.6 } } ] },
    { "type": "moba_skill", "key": "1", "x": 0.78, "y": 0.82, "radius": 0.07, "cancel_key": "Escape" }
  ]
}
```

## Типы контролов

| Тип | Поведение |
|---|---|
| `tap` | касание в точке, пока нажата клавиша |
| `joystick` | WASD → виртуальный стик: центр, радиус, плавность |
| `aim` | захват мыши, движение → перемещение касания; чувствительность X/Y, инверсия |
| `shoot` | касание одновременно с удержанием прицела |
| `swipe` | свайп от `from` к `to` за `duration_ms` |
| `repeat_tap` | повтор касаний с интервалом, пока нажата клавиша |
| `hold` | удержание (`hold`) или переключение (`toggle`) |
| `zoom` | колесо → щипок вокруг `center` |
| `macro` | последовательность касаний и пауз; запись и воспроизведение |
| `moba_skill` | нажатие → касание скилла, мышь задаёт направление, отпускание → применение |
| `gamepad` | кнопки и стики геймпада на любые контролы выше |

Экспорт и импорт — файл `.rdprofile` (тот же JSON).
