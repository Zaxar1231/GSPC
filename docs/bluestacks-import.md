# Импорт раскладок BlueStacks

> Статус: этап 8. Схема формата **не описана намеренно**: парсер и тестовые фикстуры будут
> сделаны по реальным файлам `.cfg`, которые предоставит мейнтейнер. Ничего не додумываем.

## Что известно заранее

- Раскладки лежат в папке `InputMapper` каталога данных BlueStacks в виде `.cfg` (JSON).
- Внутри — `ControlSchemes` → `GameControls` (типы вроде Tap, Dpad, Pan, Swipe, MOBASkill и др.),
  координаты в процентах.

Все детали (точные имена полей, вложенность, коды клавиш, версии формата) будут сверены по
реальным файлам.

## План

1. Собрать набор реальных `.cfg` (разные игры и версии BlueStacks) → `crates/bluestacks-import/tests/fixtures/`.
2. Описать структуры serde **по фикстурам**, игнорируя неизвестные поля (`#[serde(default)]`, без `deny_unknown_fields`).
3. Маппинг типов контролов BlueStacks → контролы RustDroid ([controls-format.md](controls-format.md)).
4. Маппинг кодов клавиш BlueStacks → имена клавиш RustDroid.
5. Отчёт об импорте: импортировано / импортировано с приближениями / пропущено (с причиной).
   Импорт никогда не падает из-за одного неподдерживаемого контрола.
6. Автопоиск установленного BlueStacks (реестр и стандартные пути), предложение импорта,
   ручной импорт файлом и drag-and-drop.
7. Тесты: snapshot-тест на каждую фикстуру, fuzz-тест парсера.
