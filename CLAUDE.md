# RustDroid — инструкции для Claude

## graphify (граф проекта)

- Если есть `graphify-out/graph.json`, вопросы об устройстве кода («как работает X», «что вызывает
  Y», «как данные идут через Z») сначала решай через `/graphify query "<вопрос>"`, а не перечитывай
  файлы. Читай исходники, только если графа не хватает.
- Граф сам не обновляется. Если нужный файл менялся после `graphify-out/graph.json` (сравни
  `git log -1 -- <файл>` с датой `graph.json`), сверяйся с исходником, а не с графом.
- После правок в нескольких файлах или в конце этапа обнови граф: `/graphify . --update`.
- `graphify-out/` в git не коммитится (см. `.gitignore`).

## ponytail (стиль работы с кодом)

- На любой задаче с кодом (написать, починить, отрефакторить, выбрать зависимость) следуй навыку
  `ponytail`: самое маленькое изменение, которое полностью решает задачу, без лишних абстракций и
  «на будущее»; ответ — короткий, понятный с одного прочтения.
- `/ponytail:ponytail-review` — перед мержем PR этапа; `/ponytail:ponytail-audit` и
  `/ponytail:ponytail-debt` — только по просьбе (дорого).
